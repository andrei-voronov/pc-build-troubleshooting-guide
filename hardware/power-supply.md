# Power Supply (PSU)

A Power Supply Unit (PSU) converts AC (alternating current) from the wall outlet into DC (direct current) used by computer components.

## Main Functions

- Converts AC to DC  
- Distributes power to components  
- Provides stable voltage  

## Common Voltages

- +3.3V → motherboard, RAM  
- +5V → storage devices, USB  
- +12V → CPU, GPU, fans  

## Connectors

- 24-pin → motherboard  
- 4/8-pin CPU → processor power  
- PCIe (6/8-pin) → GPU  
- SATA → SSD/HDD  
- Molex → older devices  

## PSU Types

- Non-modular → all cables attached  
- Semi-modular → some removable  
- Fully modular → all cables removable  

## Power Rating

Measured in watts (W)

Example:
- 500W → basic systems  
- 650W–750W → gaming / mid-range  
- 850W+ → high-end systems  

## Efficiency (80 PLUS)

- Bronze  
- Silver  
- Gold  
- Platinum  

Higher rating = better efficiency and less heat.

## Troubleshooting

- PC not turning on → check PSU  
- Random shutdowns → insufficient power  
- No fans / no lights → PSU failure
